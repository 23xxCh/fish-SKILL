# 闲鱼商品采集与新品监控

这是一个仅在 Windows 本机运行的 PySide6 桌面程序。它复用独立 Edge 浏览器中的闲鱼登录状态，既能做一次性多页采集，也能按 5/10/15/30 分钟扫描多个搜索规则，并把首次出现的新品发到手机。

程序不自动给卖家发消息。手机通知中的“直接聊天”仅在商品详情页真实提供卖家 ID 时出现；提取失败时保留 HTTPS 商品链接，由用户自行打开闲鱼联系卖家。

## 当前阶段

当前是源码测试阶段，不制作安装包，也不设置 Windows 开机启动。先运行和验收所有功能，确认实际使用没有问题后再打包给别人。

```powershell
python -m pip install -r requirements.txt
python -m goofish_collector
python -m pytest -q
```

## Agent 命令行接口

v0.5 起，Agent 可通过受控命令调用已有的本机可见浏览器流程；不使用签名接口，也不会读取或输出 Cookie、通知密钥。

```powershell
# 先由用户在桌面程序中完成一次扫码登录
python -m goofish_collector

# Agent 的一次性采集：标准输出和输出目录都会得到 JSON 摘要
python -m goofish_collector collect --keyword "相机" --pages 2 --output-dir ".\采集结果" --min-price 100 --max-price 800 --personal-only

# 只读查看已保存的新品监控任务和通知队列
python -m goofish_collector monitor-status
```

`collect` 支持关键词、页数、商品上限、输出目录、价格、地区、发布时间、商品条件及排序。完成时会输出 `completed`、Excel 路径和 `summary_json` 路径；在非交互运行中遇到登录或安全验证，会输出 `verification_required` 并保留检查点，不会尝试绕过。用户可在桌面程序或可交互终端的可见 Edge 中完成验证后再继续。

`monitor-status` 只读取本机 `monitor.db`，返回任务状态、扫描统计和待发送/已发送/失败通知数；不启动扫描、不发送通知，也不返回通知凭据或批次正文。

## Codex Skill

仓库根目录包含 `SKILL.md`，可作为 `goofish-local-collector` Skill 使用。它指导 Agent 通过桌面程序或 v0.5 命令行运行、验收和排查采集器；扫码登录、验证码、安全验证和通知凭据必须由用户在可见界面中处理。

克隆后如需让 Codex 发现该 Skill，可把仓库目录链接到 `%USERPROFILE%\.codex\skills\goofish-local-collector`。不要把本机的浏览器登录目录、数据库或采集结果提交到仓库。

## 单次采集

1. 首次使用点击“登录 / 切换账号”，在专用 Edge 中扫码登录；关闭登录窗口后，Cookie 保存在本机专用浏览器目录。
2. 在“单次采集”页输入关键词、页数、商品上限和输出目录。
3. 可选价格区间、地区、发布时间、个人闲置、验货宝、包邮和全新。
4. 点击“开始采集”。软件自动翻页、按商品 ID 去重，并生成 WPS 可打开的 Excel。
5. 登录失效或出现安全验证时，程序暂停，等待用户在可见 Edge 中手动处理。

## 新品监控

在“新品监控”页可以保存多个独立任务。每个任务包含：

- 任务名称、关键词、价格、地区、发布时间和商品条件；
- 综合/新降价/新发布排序；
- 每次扫描前 1–3 页；
- 5/10/15/30 分钟间隔；
- 可选免打扰开始和结束时间。

第一次扫描只建立基线，不发通知。后续只有该任务从未见过的商品才算新品；下架后重新出现也不会重复推送。修改关键词、筛选、排序或页数后，旧历史保留，并在下一轮静默重建新规则的基线。

一轮最多在通知中展示当前排序下的前 10 件新品，更多商品仍保存在本机数据库中。免打扰期间继续扫描，结束后合并为一条最多展示 10 件的通知。窗口关闭时，只要仍有启用任务，程序就缩到系统托盘继续运行；电脑休眠或关机时不会扫描，恢复后每个逾期任务只补跑一次。

## 手机通知

全局一次只启用一个通道，默认飞书。切换通道只影响之后创建的批次，已经排队的批次继续使用原通道。

### 飞书应用机器人

填写自己的 App ID 和 App Secret，然后按软件中的“配置向导”完成：开启机器人、申请 `im:message`、使用长连接事件订阅、添加 `im.message.receive_v1`、配置可用范围并发布版本。

点击“开始绑定（5分钟）”后，私聊机器人发送“绑定”。软件通过飞书官方 Python SDK 的长连接取得发送者 `open_id`，一台电脑只允许绑定一个接收用户；换人前必须先解绑。飞书长连接不需要公网回调服务器。

### WxPusher

只需填写 `SPT_...` 极简推送令牌，不需要 AppToken 和 UID。SPT 相当于私人收件地址，泄露后别人可以向该用户推送消息，应妥善保管。软件提供官方说明入口和测试通知按钮。

## 本地数据和安全

- 浏览器登录状态：`%LOCALAPPDATA%\GoofishLinkCollector\browser-profile`
- 任务数据库：`%LOCALAPPDATA%\GoofishLinkCollector\monitor.db`
- App Secret、飞书绑定 `open_id` 和 WxPusher SPT 使用当前 Windows 用户的 DPAPI 加密。
- 飞书临时访问令牌只缓存在内存，不写日志、不写 Excel。
- 通知发送前先写本地待发送队列；失败后按 5 秒、30 秒、120 秒重试，最终失败会保留错误和批次，不把商品标记为已通知。
- Excel 只在用户点击导出时生成；商品 HTTPS 链接不能为空，聊天链接只写入真实提取成功的记录。

## 使用边界

- 不破解验证码，不绕过登录、安全验证或闲鱼风控。
- 不自动向卖家发送招呼、询价或其他消息。
- 不建设云端账号或通知服务器；数据库、Cookie 和完整采集结果不上传。
- 飞书或 WxPusher 会接触通知正文和其中的商品链接。
- 闲鱼页面结构变化后，筛选、翻页或聊天地址提取规则可能需要维护。
- 请仅以合理频率处理有权访问的数据，并遵守平台规则和适用法律。
