# 闲鱼商品采集与定时推送

这是一个仅在 Windows 本机运行的 PySide6 桌面程序。它复用独立 Edge 浏览器中的闲鱼登录状态，可做一次性多页采集，也可按 5/10/15/30/60 分钟重复执行当前采集条件，并把每次的真实结果推送到飞书。

程序不自动给卖家发消息。手机通知中的“直接聊天”仅在商品详情页真实提供卖家 ID 时出现；提取失败时保留 HTTPS 商品链接，由用户自行打开闲鱼联系卖家。

## 当前阶段

当前是本机运行与验收阶段。可构建为免安装的 Windows 便携文件夹；不设置 Windows 开机启动。先完成一次真实登录、飞书测试通知和定时采集验收，再交付给其他人使用。

### 自动更新

桌面程序每天静默检查一次本项目的 GitHub 正式发布，也可点击首页标题下方的“检查更新”。发现新版本时，软件只在你确认后才下载；下载包必须同时满足发布版本匹配、GitHub HTTPS 地址和 SHA-256 摘要校验。校验完成后软件退出，由本机安装助手替换便携文件夹并自动重启；旧版文件夹会保留为带时间戳的备份，安装失败会恢复旧版。采集、登录或飞书推送进行中不能启动更新，程序不会后台自动覆盖文件。

```powershell
python -m pip install -r requirements.txt
python -m goofish_collector
python -m pytest -q
```

## Windows 桌面客户端首次使用

解压便携版后，双击 `XianyuLinkCollector.exe`。在 **单次采集** 页右侧点击 **设置飞书 / 绑定**，按以下三步完成飞书：

1. 填写并保存 App ID 与 App Secret（只加密保存在这台 Windows 电脑）。
2. 点击“开始绑定（5分钟）”，在飞书私聊机器人发送“绑定”。
3. 点击“测试飞书”，确认手机实际收到通知后，再启动定时采集。

这三步不能跳过：程序收到发送接口成功响应，不等于手机已经实际收到通知。

## Agent 命令行接口

v0.5 起，Agent 可通过受控命令调用已有的本机可见浏览器流程；不使用签名接口，也不会读取或输出 Cookie、通知密钥。

```powershell
# 先由用户在桌面程序中完成一次扫码登录
python -m goofish_collector

# Agent 的一次性采集：标准输出和输出目录都会得到 JSON 摘要
python -m goofish_collector collect --keyword "相机" --pages 2 --output-dir ".\采集结果" --min-price 100 --max-price 800 --personal-only

```

`collect` 支持关键词、页数、商品上限、输出目录、价格、地区、发布时间、商品条件及排序。完成时会输出 `completed`、Excel 路径和 `summary_json` 路径；在非交互运行中遇到登录或安全验证，会输出 `verification_required` 并保留检查点，不会尝试绕过。用户可在桌面程序或可交互终端的可见 Edge 中完成验证后再继续。

## Codex Skill

仓库根目录包含 `SKILL.md`，可作为 `goofish-local-collector` Skill 使用。它指导 Agent 通过桌面程序或命令行运行、验收和排查采集器；扫码登录、验证码、安全验证和通知凭据必须由用户在可见界面中处理。

克隆后如需让 Codex 发现该 Skill，可把仓库目录链接到 `%USERPROFILE%\.codex\skills\goofish-local-collector`。不要把本机的浏览器登录目录、数据库或采集结果提交到仓库。

## 单次采集

1. 首次使用点击“登录 / 切换账号”，在专用 Edge 中扫码登录；关闭登录窗口后，Cookie 保存在本机专用浏览器目录。
2. 在“单次采集”页输入关键词、页数、商品上限和输出目录。
3. 可选价格区间、地区、发布时间、个人闲置、验货宝、包邮和全新。
4. 默认只导出 Excel。若本轮也要推送飞书，先在右侧“任务操作”勾选“完成后推送飞书”；任务结束后该开关会自动关闭。
5. 点击“开始采集”。软件自动翻页、按商品 ID 去重，并生成 WPS 可打开的 Excel。
6. 登录失效或出现安全验证时，程序暂停，等待用户在可见 Edge 中手动处理。

单次推送与 Excel 导出相互独立：Excel 始终保留完整采集结果；只有符合“飞书推送条件”的商品才发到飞书。单次推送直接发送，不进入定时任务的本机重试队列。

## 定时采集与飞书推送

在 **单次采集** 填好关键词、页数、输出目录和筛选条件后：

1. 右侧选择 5/10/15/30/60 分钟间隔。
2. 在 **设置飞书 / 绑定** 完成配置、绑定和实收测试。
3. 点击右侧 **任务健康**：可勾选“只推送新增/价格变化”，设置“最高推送价”、必须包含词和排除词。示例：最高推送价填 `300`，必须包含词填 `华为, 耳机`，即只推送价格不高于 ¥300 且同时含有两个词的商品。未识别价格的商品在启用最高推送价时不会推送。
4. 保存推送条件。首次启用或规则变化后，新增/价格变化基线会重新建立；之后无变化时只导出 Excel，不发飞书。
5. 点击 **启动定时采集**。它会立即跑第一轮；此后每轮完成后等待设定间隔再执行，避免两个 Edge 同时占用本机登录目录。

每次成功采集仍会完整导出 Excel；飞书卡片显示总数和前 10 条商品的主图、标题、价格、地区与真实 HTTPS 商品链接。视频商品优先使用视频封面；封面缺失、纯白/透明占位图、下载或上传失败时，该商品自动降级为文字和“查看商品”按钮，不会发送空白图片区。更多商品只在本机 Excel 中查看。商品主图只在当前推送时下载并上传飞书，不保存图片字节到本机历史。每轮飞书结果会先写入本机投递队列；失败按 5、30、120 秒自动重试，重启软件后也会继续未完成的投递。若定时采集本身失败，也会立即向已绑定的飞书用户发送关键词、时间和错误摘要。右侧 **任务健康** 可查看最近成功、结果文件、飞书状态及待投递数量。停止定时采集不会中断当前浏览器操作，当前轮仍会导出，但不会再发送飞书。关闭窗口时，只要定时采集已启动，程序就缩到系统托盘继续运行；电脑必须保持开机、联网且不休眠。

### 飞书应用机器人

填写自己的 App ID 和 App Secret，然后按软件中的“配置向导”完成：开启机器人、申请 `im:message` 和 `im:resource`、使用长连接事件订阅、添加 `im.message.receive_v1`、配置可用范围并发布版本。`im:resource` 用于上传商品主图；申请权限后必须发布新版本。程序不会替你修改飞书应用权限；权限尚未生效时仍会降级为文字和商品链接推送。

点击“开始绑定（5分钟）”后，私聊机器人发送“绑定”。软件通过飞书官方 Python SDK 的长连接取得发送者 `open_id`，一台电脑只允许绑定一个接收用户；换人前必须先解绑。飞书长连接不需要公网回调服务器。

## 本地数据和安全

- 浏览器登录状态：`%LOCALAPPDATA%\GoofishLinkCollector\browser-profile`
- 本地设置：`%LOCALAPPDATA%\GoofishLinkCollector\monitor.db`（包含定时规则、变化推送基线、投递队列与任务健康；历史监控数据不会自动删除，但新版不再运行或显示它。）
- App Secret 和飞书绑定 `open_id` 使用当前 Windows 用户的 DPAPI 加密。
- 飞书临时访问令牌只缓存在内存，不写日志、不写 Excel。
- 每轮采集结束都会生成 Excel；商品 HTTPS 链接不能为空，聊天链接只写入真实提取成功的记录。

## 使用边界

- 不破解验证码，不绕过登录、安全验证或闲鱼风控。
- 不自动向卖家发送招呼、询价或其他消息。
- 不建设云端账号或通知服务器；数据库、Cookie 和完整采集结果不上传。
- 飞书会接触推送正文和其中的商品链接。
- “查看商品”使用闲鱼 HTTPS 网页链接，飞书手机端会在内置浏览器中打开；程序不会拼接未经验证的闲鱼 App 私有 URI。若要实现一键唤起闲鱼 App，需要另行接入并验证官方分享链接或自有 HTTPS 跳转页。
- 闲鱼页面结构变化后，筛选、翻页或聊天地址提取规则可能需要维护。
- 请仅以合理频率处理有权访问的数据，并遵守平台规则和适用法律。
